# Feature Specification: 能登北部全域展開・1mDEM移行(DEM Cross-Section Viewer — Full Northern Noto Expansion)

**Feature Branch**: `002-expand-northern-noto`

**Created**: 2026-08-16

**Status**: Draft

**Input**: User description: "能登半島北部DEM断面図WebGISを、これまでのテスト地域(町野地区)から能登北部全域(輪島市・珠洲市・能登町・穴水町を中心とする範囲)に拡張する。あわせて、DEMの著作権保護を考慮し、当初想定していた0.5mオリジナル解像度のDEMではなく、1mにリサンプルした(または1m解像度で作成された)DEMを使用する方針に変更する。既存機能001-dem-cross-sectionのアーキテクチャはそのまま踏襲する。"

## Context

[001-dem-cross-section](../001-dem-cross-section/spec.md) で、町野地区(輪島市の一部)をテスト範囲として断面図生成・複数時期比較・PNGダウンロード等のコア機能はすべて実装済み・実機検証済みである。本機能はその技術的な仕組み(Leaflet地図、COG+HTTP Range Request、EPSG:6675座標変換、複数時期比較、PNG出力)を変更せず、対象とするDEMデータの**範囲**と**解像度**の方針のみを変更する、データ中心の拡張である。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 能登北部4市町全域で任意地点の断面図を作成する (Priority: P1)

ユーザーは、これまでのテスト範囲(町野地区)に限らず、輪島市・珠洲市・能登町・穴水町を中心とする能登半島北部全域の任意の地点で測線を指定し、001-dem-cross-sectionで確立した断面図生成(距離-標高グラフ、複数時期比較、PNGダウンロード)を利用できる。

**Why this priority**: 「能登半島北部の地形変化を捉える」というサービスの本来の目的(idea.md, 001 spec.md)は、限定的なテスト地域だけでは達成されない。対象範囲の拡張こそが本機能の中核価値。

**Independent Test**: 町野地区外(例: 珠洲市中心部や穴水町沿岸部)で2点をクリックして測線を指定し、断面図が001と同様に表示されることを確認する。

**Acceptance Scenarios**:

1. **Given** 地図が能登北部全域を表示している、**When** ユーザーが町野地区以外の地点(輪島市街地・珠洲市・能登町・穴水町のいずれか)で測線を指定する、**Then** 001と同様に距離-標高の断面図が表示される。
2. **Given** 断面図が表示されている、**When** ユーザーが複数時期(地震前・地震後・豪雨後)の表示を比較する、**Then** 各時期の断面線が色分けされ、凡例で個別に表示/非表示を切り替えられる(001 User Story 2を踏襲)。

---

### User Story 2 - データセットごとに異なるデータ提供範囲を明確に把握する (Priority: P2)

ユーザーは、同一の測線であっても、DEMデータセット(地震前・地震後・豪雨後)ごとに実際の測量範囲が異なり、一部の時期でのみデータが欠損する場合があることを、断面図上で明確に判別できる。

**Why this priority**: 全域展開に伴い、3時期のDEM原本の測量範囲が互いに一致しない(豪雨後DEMは地震前後DEMより測量範囲が狭い)ことが判明した。この差異をユーザーに誤解なく伝えることは、地形変化の比較という本サービスの信頼性に直結する。

**Independent Test**: 3時期のうち1時期のみデータが存在しない区間を含む測線を指定し、その時期の断面線のみが当該区間で途切れて表示され、他の時期は途切れずに表示されることを確認する。

**Acceptance Scenarios**:

1. **Given** 測線の一部区間で特定時期のDEMのみデータが存在しない、**When** 断面図を生成する、**Then** データが存在しない時期の線のみが当該区間で途切れ、他の時期の線は連続して表示される(001 Edge Cases・FR-012を踏襲)。

---

### Edge Cases

- 測線の一部または全部が、能登北部全域の共通クロップ範囲(bbox)外にある場合、その区間はすべての時期でデータ欠損として表示される(001 Edge Casesを踏襲)。
- 測線の一部が、共通bbox内ではあるが特定データセットの実測範囲外にある場合、そのデータセットのみ欠損として表示され、他のデータセットは表示され続ける(User Story 2)。
- サンプリング間隔がDEMの解像度(1m)より小さい値で指定された場合、隣接するDEM画素値から最近傍法で標高を算出する(001の閾値記述を0.5m→1mに更新)。
- 対象範囲が拡張されたことで、測線長が10km・総サンプル点数20,000点という既存の確認閾値(001 spec.md Edge Cases)に到達するケースが町野地区限定時より頻発する可能性がある。閾値自体は001の既定値をそのまま踏襲し、実運用の様子を見て調整する。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは、輪島市・珠洲市・能登町・穴水町を包含する能登半島北部全域の範囲内で、001-dem-cross-sectionで実装済みの断面図生成機能(測線指定・サンプリング間隔指定・複数時期比較・断面図PNGダウンロード・地図PNGダウンロード)を提供しなければならない。
- **FR-002**: システムが使用するDEMの解像度は1mでなければならない。著作権保護の観点から、0.5mのオリジナル解像度DEMをそのままの解像度で配信・使用してはならない。
- **FR-003**: 提供する3時期(地震前・地震後・豪雨後)のDEMのうち、元の測量解像度が1mより高精細だったデータセットは、1mへリサンプル(平均法)した上で提供しなければならない。
- **FR-004**: 各DEMデータセットは、能登北部4市町を包含する共通のクロップ範囲(bbox)に整形された上で配信されなければならない。
- **FR-005**: データセットごとに実際の測量範囲が共通bboxより狭い場合、範囲外の区間は当該データセットのみのデータ欠損として扱い、断面図上で当該時期の線のみを途切れさせて表示しなければならない(他時期の表示に影響を与えない)。
- **FR-006**: DEM原本に含まれる、正規のNoData値として登録されていない異常なダミー値(例: 測量・GIS処理由来の仮値)は、配信用データ作成時点でNoDataとして正しく無効化されていなければならない。ダミー値が正しく除去されないまま配信された場合、断面図に地形として不自然な垂直スパイクが生じる(001 research.md R8で同種の問題が確認・修正済み)。

### Key Entities *(include if feature involves data)*

- **DEMデータセット (DEM Dataset)**: 001の `DemDatasetConfig` を踏襲。`resolutionM` は `0.5` から `1` に変更する。データセットごとに実際にデータが存在する空間範囲(実測範囲)が異なり得る点が、町野地区限定運用時との相違点。
- **対象範囲 (Coverage Extent)**: 能登北部4市町(輪島市・珠洲市・能登町・穴水町)を包含する共通のクロップ範囲(bbox)。全DEMデータセット・タイル背景に共通する、断面図生成・地図表示の想定対象範囲。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: ユーザーは、町野地区に限らず能登北部4市町の範囲内であれば、どこでも測線を指定して断面図を生成できる。
- **SC-002**: 1m解像度への変更後も、001 SC-001(測線・サンプリング間隔指定から10秒以内に断面図表示)は維持される。
- **SC-003**: 1m解像度に変更したことによる断面図の縦断形状の変化は、地震・豪雨前後の隆起・沈降・侵食・堆積といった地形変化を目視で識別する実務上の判読性を損なわない(001 SC-005を踏襲)。
- **SC-004**: 断面図上で、データセットごとのデータ提供範囲の違い(部分的な欠損)が、ユーザーにとって「エラー」ではなく「その時期はデータがない区間」として明確に判別できる。

## Assumptions

- 対象4市町(輪島市・珠洲市・能登町・穴水町)を包含する共通クロップ範囲は、行政界と完全一致する矩形である必要はなく、それらを十分に包含するバウンディングボックス(EPSG:6675: おおよそ x: -43500〜17500, y: 113000〜172500、WGS84でおよそ東経136.68〜137.36度・北緯37.02〜37.55度)とする。
- 豪雨後のDEMは元々0.5m解像度で作成されていたため、平均法により1mへリサンプルする。地震前・地震後のDEMは提供時点で既に1mであり、追加のリサンプルは行わない。
- 0.5m→1mへの解像度変更は、本サービスの用途(広域の地形変化の可視化・比較)において実用上大きな精度低下を招かないとの判断に基づく(idea.md・ユーザー判断)。
- 3時期のDEM原本は、いずれも実際の測量範囲が共通クロップ範囲より狭い可能性があり、特に豪雨後DEMは他の2時期より測量範囲が狭い。これは001 Edge Casesで定義済みの「データ欠損」として扱う想定の範囲内であり、新たな仕様追加は不要とする。
- DEM原本に含まれるダミー値混入(NoData未設定の仮値)の検出・修正は、断面図生成機能そのものの実装ではなく、配信用データを準備する運用者側の前処理作業であり、001 research.md R8の手順(疑わしい値の統計的検出とSetNullによる修正)を踏襲する。
- タイル背景・地図PNGエクスポート等、DEM以外の001の機能・制約(FR-001〜FR-016、Technology Constraints)はすべてそのまま有効とする。
