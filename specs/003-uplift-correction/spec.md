# Feature Specification: 隆起補正断面図

**Feature Branch**: `003-uplift-correction`

**Created**: 2026-09-07

**Status**: Draft

**Input**: User description: "能登半島地震による広域的な地殻変動(隆起)を考慮した断面図補正機能を追加する。能登半島北部では地震により地域ごとに大きく異なる量の隆起が発生した。断面図作成時に、ユーザーが隆起量(m単位)を入力すると、地震前DEM(pre-earthquake)の標高値にその隆起量を加算した「隆起補正後」の系列を断面図に追加表示できるようにする。これにより、地すべり等の地形改変が起きなかった地点では、隆起補正後の地震前地形が地震後(post-earthquake)の地形とほぼ一致するグラフになり、隆起補正だけでは説明できない標高変化(=地すべり等による地形改変)を視覚的に識別しやすくする。隆起量は断面ごとにユーザーが手入力する単一の数値(その断面内では一定とみなす簡易モデル)とし、既存の断面図生成(DEMサンプリング)をやり直さずに、既に取得済みの地震前標高データにオフセットを加えるだけの軽量な処理として実装する。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 隆起量を入力して補正後の地震前地形を重ね描画する (Priority: P1)

ユーザーは測線上の断面図を作成した後、その地点における隆起量(m)を入力する。すると、地震前DEMの標高値に隆起量を加算した「隆起補正後」の系列が、既存の3系列(地震前・地震後・豪雨後)に追加して断面図上に描画される。地すべり等の地形改変がなかった区間では、この補正後系列が地震後系列とほぼ重なって見えることで、隆起だけでは説明できない標高変化(=地形改変)を視覚的に識別できる。

**Why this priority**: 本機能の核心的価値そのもの。これがなければ機能として成立しない。

**Independent Test**: 断面図を作成済みの状態で隆起量に0以外の数値を入力し、補正後系列が地震前系列から入力値ぶん平行移動した形で追加表示されることを確認する。

**Acceptance Scenarios**:

1. **Given** 断面図が作成済みである、**When** ユーザーが隆起量欄に0以外の数値(例: 1.5)を入力する、**Then** 「地震前(隆起補正)」系列が(追加の操作なしに自動的に)断面図に追加され、各距離点の値が地震前系列の値+1.5mになる。あわせて、グラフ内に適用した隆起量(例: 「隆起補正 +1.5mを適用」)が明示的に表示され、補正が適用されたことが一目で分かる。
2. **Given** 隆起補正系列が表示されている、**When** ユーザーが隆起量の値を変更する、**Then** DEMの再取得(サンプリングのやり直し)を行うことなく、補正後系列の値およびグラフ内の隆起量表示が新しい隆起量に基づいて即座に更新される。
3. **Given** 地震前DEMの標高がその距離点でNoData(null)である、**When** 補正後系列を計算する、**Then** その距離点の補正後系列の値もNoData(null)のままになる(架空の値を生成しない)。

---

### User Story 2 - 隆起補正前(元)の地震前系列の表示・非表示を切り替える (Priority: P2)

隆起量に0以外の値を入力すると補正後系列は自動的に表示されるため、元の(補正前の)地震前系列との重複表示が煩雑になる場合がある。ユーザーは、隆起補正前の地震前系列を表示し続けるか、非表示にして補正後系列と地震後・豪雨後系列の比較に絞るかを切り替えられる。

**Why this priority**: 補正後系列と元の地震前系列を両方常時表示すると視認性を損なう場合があるため、切替は利便性を大きく高めるが、P1(補正後系列の自動表示)がなくても価値の一部は成立する。

**Independent Test**: 隆起量を0以外に設定して補正後系列が表示された状態で、「隆起補正前の地震前地形も表示する」の切替コントロールを操作し、元の地震前系列が非表示になること、再度操作すると表示に戻ること、地震後・豪雨後系列や補正後系列の表示状態には影響しないことを確認する。

**Acceptance Scenarios**:

1. **Given** 隆起量が0以外に設定され補正後系列が表示されている、**When** ユーザーが「隆起補正前の地震前地形も表示する」のチェックを外す、**Then** 元の(補正前の)地震前系列のみが非表示になり、補正後系列・地震後系列・豪雨後系列の表示状態には影響しない。
2. **Given** 前項の状態からチェックを再度入れる、**When** ユーザーが操作する、**Then** 元の地震前系列が再び表示される。
3. **Given** 隆起量が0または無効値である(補正が適用されていない)、**When** この切替コントロールを操作する、**Then** 補正後系列が存在しないため、地震前系列の表示状態は変化しない。

---

### User Story 3 - 補正後系列の線の色・太さをカスタマイズし、PNG出力に含める (Priority: P3)

ユーザーは他のデータセット系列と同様に、補正後系列の線の色・太さを変更できる。また、断面図をPNGとしてダウンロードした際、補正後系列も画像に含まれる。

**Why this priority**: 既存機能(系列スタイル変更・PNGダウンロード)との一貫性を保つための拡張であり、なくても主要な価値(P1)は成立する。

**Independent Test**: 補正後系列表示中に色・太さを変更して見た目が変わることを確認し、断面図PNGをダウンロードして補正後系列が画像内に描画されていることを確認する。

**Acceptance Scenarios**:

1. **Given** 補正後系列が表示されている、**When** ユーザーがその系列の色または線幅を変更する、**Then** 断面図上の該当系列の見た目が即座に変わる。
2. **Given** 補正後系列が表示されている、**When** ユーザーが断面図をPNGでダウンロードする、**Then** 出力画像に補正後系列が他の系列と同様に描画されている。

### Edge Cases

- 隆起量に0を入力した場合: 補正後系列は地震前系列と完全に一致する(処理上は特別扱いせず、そのまま加算0として扱う)。
- 隆起量に負の数値を入力した場合: 地震後に隆起ではなく沈降が生じた地域を想定し、そのまま減算として扱う(入力を拒否しない)。
- 隆起量に数値以外・空欄を入力した場合: 補正後系列は表示しない、または直前の有効値を保持する形とし、エラー状態を分かりやすく示す。
- 新しい測線を描き直して断面図を再作成した場合: 隆起量の入力値はその都度ユーザーが確認・再入力できるよう、直前の値を保持したままでよい(自動リセットはしない)。
- 地震前データセット自体がその断面で全区間NoDataの場合: 補正後系列も全区間NoDataとなり、実質何も描画されない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは、断面図作成後にユーザーが隆起量をメートル単位の数値で入力できるUIを提供しなければならない。
- **FR-002**: システムは、入力された隆起量を地震前(pre-earthquake)データセットの各距離点の標高値に加算した「隆起補正後」系列を算出しなければならない。
- **FR-003**: システムは、隆起量が変更されるたびにDEMの再サンプリング(データ取得のやり直し)を行わず、既に取得済みの地震前標高データに対するオフセット加算のみで補正後系列を再計算しなければならない。
- **FR-004**: システムは、地震前データセットの標高値がNoData(null)である距離点について、補正後系列の値もNoData(null)として維持し、値を補間・捏造してはならない。
- **FR-005**: システムは、補正後系列を断面図上に既存の系列(地震前・地震後・豪雨後)と並べて描画し、系列名(凡例)およびグラフ内の明示的な表示(タイトル等)の両方から、隆起補正後の系列であること・適用した隆起量が分かるようにしなければならない。
- **FR-006**: システムは、隆起量に0以外の有効な数値が入力された場合、補正後系列を自動的に(追加の表示操作なしに)断面図へ表示しなければならない。また、ユーザーが元の(補正前の)地震前系列の表示/非表示を、地震後・豪雨後・補正後系列の表示状態とは独立に切り替えられるようにしなければならない。
- **FR-007**: システムは、ユーザーが補正後系列の線の色・太さを他のデータセット系列と同様の方法で変更できるようにしなければならない。
- **FR-008**: システムは、断面図PNGダウンロード機能において、補正後系列が表示状態であれば出力画像にも含めなければならない。
- **FR-009**: システムは、隆起量として0および負の数値の入力を許容しなければならない(有限の数値であればよい)。
- **FR-010**: システムは、隆起量の入力欄に無効な値(数値以外・空欄)が入力された場合、補正後系列の表示を更新せず、既存の断面図表示(他系列)に影響を与えてはならない。

### Key Entities

- **UpliftCorrection**: 現在の断面図に対して適用される隆起補正の設定。隆起量(メートル、正負を許容)と、補正対象のベースとなるデータセット(地震前データセット)への参照を持つ。断面図(測線)ごとに保持され、複数のデータセットにまたがる補正や、測線内で隆起量を変化させる(空間的に変動する)モデルは対象外とする。
- **隆起補正後系列**: 断面図上の距離点ごとに、ベースとなるデータセットの標高値+隆起量として算出される値の並び。既存の距離-標高データ構造と同じ形式で扱われ、独立したDEMデータセットとしては永続化されない。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: ユーザーが隆起量を入力してから1秒未満で、補正後系列が断面図に反映される(DEM再取得を伴わないため)。
- **SC-002**: 地すべり等の地形改変がなかった区間において、ユーザーは補正後系列と地震後系列がほぼ一致することを断面図上で目視確認できる。
- **SC-003**: 地震前データセットがNoDataの距離点は、補正後系列においても100%NoDataのまま維持される(捏造値が発生しない)。
- **SC-004**: ユーザーは断面図を再作成する(測線を引き直す)ことなく、隆起量の値を何度でも変更して結果を比較できる。

## Assumptions

- 隆起量は断面(測線)全体で一定とみなす簡易モデルとし、測線内で隆起量が空間的に変化するモデル(区間ごとの補間等)は本機能の対象外とする。
- 補正の対象となるベースデータセットは「地震前(pre-earthquake)」データセットのみとし、他のデータセット(地震後・豪雨後)への補正適用は対象外とする。
- 隆起量はユーザーの手入力によるものとし、外部の地殻変動モデル・GNSS観測データ等から自動算出する機能は対象外とする。
- 隆起量の初期値は0mとし、ユーザーが0以外の有効な値を入力するまでは補正後系列を表示しない(既存の3系列のみの表示を初期状態とする)。0以外の値が入力されると、追加の表示操作なしに補正後系列を自動表示する。
- 「隆起補正前の地震前地形も表示する」切替の初期状態はオン(表示)とし、既存の地震前系列の見え方を変えない。オフにする操作は、補正後系列が実際に表示されている場合にのみ意味を持つ(補正が未適用の間は地震前系列の表示状態に影響しない)。
- 断面図(測線)を新しく作成し直した場合でも、直前に入力した隆起量の値はUI上に保持してよい(明示的なリセット操作は求めない)。
