# Quickstart: 能登北部全域展開・1mDEM移行の検証

001-dem-cross-sectionの[quickstart.md](../001-dem-cross-section/quickstart.md)のシナリオ構成
(地図表示・測線描画・断面図生成・複数時期比較・PNGダウンロード)をそのまま踏襲する。本ドキュメント
は、002固有の追加検証項目のみを記載する。

## 前提

- research.md R9のパイプラインで作成した3つのCOG(能登北部全域・1m、共通クロップ範囲)が、
  HTTP Range Request・CORSを許可する静的ストレージ(GCS等)へアップロード済みであること。
- `src/config/datasets.ts` の `demDatasets[]` が、新しいCOGの URL・`resolutionM: 1` を指すよう
  更新済みであること。

## シナリオ 1: 町野地区外での断面図生成(spec.md User Story 1)

1. アプリを開き、地図が能登北部全域(輪島市・珠洲市・能登町・穴水町を包含する範囲)を表示する
   ことを確認する。
2. 町野地区**以外**の地点(例: 珠洲市中心部、穴水町沿岸部)で2点をクリックして測線を指定する。
3. サンプリング間隔を指定して断面図を生成する。
4. 断面図が表示されること、SC-002(10秒以内表示)を満たすことを確認する。

## シナリオ 2: データセットごとに異なる欠損区間の表示(spec.md User Story 2)

1. 豪雨後データセットの実測範囲外(かつ地震前後データセットの実測範囲内)となる区間を含む測線を
   指定する(research.md R9: 豪雨後データセットは南北方向の実測範囲が他の2時期より狭い)。
2. 断面図生成後、豪雨後の系列のみが当該区間で途切れ、地震前・地震後の系列は連続して表示される
   ことを確認する(spec.md SC-004)。

## シナリオ 3: 性能の実機再検証(plan.md Technical Context, research.md R2)

1. 能登北部全域スケールで、6km超・10km前後の長い測線を複数の地点(町野地区内・町野地区外)で
   指定し、断面図生成が001実機検証時と同等の応答時間で完了することを確認する。
2. 明らかな遅延・応答不能が発生した場合は、001 research.md R2の「COGタイル単位読込」の前提
   (タイル境界と測線の関係)が全域版COGでも成立しているかを再調査する。

## シナリオ 4: CRS整合性の確認(research.md R9のリスク項目)

1. 既知の地物(例: 主要な岬・港湾施設)付近で測線を指定し、断面図の標高値が地理院地図等の
   参考情報と大きくズレていないことを目視で確認する(前処理パイプラインがローカルGDAL環境の
   `proj.db`欠如の影響を受けていないことの実データでの裏付け)。
