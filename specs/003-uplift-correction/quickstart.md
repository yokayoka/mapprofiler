# Quickstart: 隆起補正断面図の検証

001-dem-cross-sectionの[quickstart.md](../001-dem-cross-section/quickstart.md)の前提
(地図表示・測線描画・断面図生成)をそのまま踏襲する。本ドキュメントは003固有の検証項目のみ
記載する。

## シナリオ 1: 隆起補正系列の追加表示(spec.md User Story 1)

1. アプリを開き、地すべり等の地形改変が起きていないと想定される区間(例: 平坦な台地上)を含む
   測線を指定し、断面図を生成する(地震前・地震後・豪雨後の3系列が表示される)。
2. 隆起量の入力欄に、その地域で報告されている隆起量(m)に近い正の数値(例: 2.0)を入力する。
3. 追加の表示操作なしに「地震前(隆起補正 +2.0m)」系列が自動的に追加表示され、地震前系列を
   上方に平行移動した形になることを確認する。あわせて、グラフ内に「隆起補正 +2.0mを適用」等の
   表示が現れ、補正が適用されたことが明示されることを確認する(FR-005)。
4. 地形改変が起きていない区間で、補正後系列と地震後系列がほぼ重なって見えることを目視確認する
   (SC-002)。

## シナリオ 2: DEM再取得なしでの即時反映(spec.md FR-003, SC-001)

1. シナリオ1の状態から、隆起量の値を変更する(例: 2.0 → 1.0)。
2. ネットワークタブ等で新たなDEM(COG)へのリクエストが発生していないこと、かつ断面図の
   補正後系列が1秒未満で新しい値に更新されることを確認する。

## シナリオ 3: NoData(欠損)の伝播(spec.md FR-004)

1. 地震前データセットの実測範囲外を含む測線を指定して断面図を生成する(地震前系列が一部区間で
   途切れる)。
2. 隆起量を入力し、補正後系列も同じ区間で途切れる(値が捏造されない)ことを確認する。

## シナリオ 4: 元の地震前系列の表示切替・スタイル変更・PNGダウンロード(spec.md User Story 2, 3)

1. 隆起量を0以外に設定し補正後系列が表示された状態で、「隆起補正前の地震前地形も表示する」の
   チェックを外し、元の(補正前の)地震前系列のみが非表示になること、地震後・豪雨後・補正後系列の
   表示状態には影響しないことを確認する(FR-006)。再度チェックを入れると元の系列が表示に戻る
   ことを確認する。
2. 補正後系列の色・線幅を変更し、見た目が変わることを確認する。
3. 断面図をPNGでダウンロードし、補正後系列が画像に含まれていることを確認する。

## シナリオ 5: 無効な入力値・補正未適用時の切替(spec.md Edge Cases, FR-010)

1. 隆起量欄を空欄にする、または数値以外を入力する。
2. 補正後系列が表示されない(または直前の有効な表示状態が維持される)こと、他の3系列の表示に
   影響しないことを確認する。
3. 隆起量が0または無効値の状態(補正未適用)で「隆起補正前の地震前地形も表示する」を操作しても、
   地震前系列の表示状態が変化しないことを確認する。
